Important Notes

⚠ Critical: Set Buck Voltage First

Before connecting the ESP32, power the buck converter with batteries and use a multimeter to adjust the trimmer potentiometer until output reads exactly 5.0V. Too high will fry the ESP32.

⚠ GPIO 34 & 35 — Input Only

These pins have NO internal pull-up resistors. You MUST add a 10kΩ external resistor from each pin to 3.3V. Without this, button readings will be random noise.

📡 I²C Shared Bus
  • OLED uses address 0x3C
  • DS3231 uses address 0x68
  • Both share GPIO 21 (SDA) and GPIO 22 (SCL)
  • No conflict — different addresses
✅ Button Wiring Pattern

Wire each button: one leg to GPIO pin, other leg to GND. Then a 10kΩ resistor from that same GPIO to 3.3V. Button press pulls GPIO LOW — code uses digitalRead() == LOW to detect press.
